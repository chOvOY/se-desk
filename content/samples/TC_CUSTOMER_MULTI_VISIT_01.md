# 测试用例：同一客户两次拜访（端到端）

> 目的：验证客户档案、多访注入、拜访记数、合并事实/缺口。  
> 建议环境：本地已启动 `python -m app.run`，可用 dry_run（不耗 API）。

---

## 用例 ID

`TC-CUSTOMER-MULTI-VISIT-01`

## 前置条件

1. 服务在 `http://127.0.0.1:8765` 可访问（`GET /api/health` 返回 ok）  
2. 浏览器强刷前端，或用 API / 脚本执行  
3. 可为 dry_run（演示模式）

## 测试数据

### 客户

| 字段 | 值 |
|------|-----|
| name | 华南精工汽配（测试） |
| one_liner | 十余工厂，传统 VPN 要收敛暴露面并补齐远程审计 |
| scene_default | ict |

### 拜访 #1

| 字段 | 值 |
|------|-----|
| meeting_goal | discovery |
| scene | ict |

| competitors | 某头部安全厂商 |
| dry_run | true |

### 拜访 #1 合并进档案

| 类型 | 内容 |
|------|------|
| add_facts | 有 AD；远程主要靠传统 VPN；账号存在共用；旧 VPN 需并存；希望 1～2 分支先试点 |
| add_gaps | 等保级别未知；试点工厂未定；竞品已承诺范围未知 |

### 拜访 #2

| 字段 | 值 |
|------|-----|
| meeting_goal | solution |
| scene | ict |
| notes | 二访：周工确认试点工厂定为东莞一厂；等保二级；竞品尚未正式报价。希望下周看方案。 |
| dry_run | true |

| 类型 | 内容 |
|------|------|
| add_facts | 试点工厂=东莞一厂；等保二级 |
| remove_gaps | 等保级别未知；试点工厂未定 |
| add_gaps | 竞品正式报价未知；方案会时间待定 |

---

## 步骤与期望

| 步骤 | 操作 | 期望结果 |
|------|------|----------|
| 1 | `POST /api/customers` 创建上述客户 | 返回 id；visit_count=0 |
| 2 | 选该客户，拜访#1 数据 `POST /api/generate`（record_visit=true, dry_run=true） | 返回 markdown；visit_no=1；客户 visit_count=1 |
| 3 | `POST /api/customers/{id}/merge` 合并拜访#1 事实/缺口 | confirmed_facts 含「有 AD」；open_gaps 含「等保级别未知」 |
| 4 | 拜访#2 `POST /api/generate` | visit_no=2；**请求侧档案摘要**含累计事实与缺口（可通过再 GET 客户 + 逻辑断言；或看生成稿是否引用东莞前档案信息） |
| 5 | `GET /api/customers/{id}` | visit_count=2；visits 长度=2；近访摘录可见 |
| 6 | merge 拜访#2 | 事实含「试点工厂=东莞一厂」「等保二级」；缺口中「等保级别未知」「试点工厂未定」已移除 |

## 通过准则（Pass）

- [ ] 同一 customer_id 下拜访从 1 增到 2  
- [ ] 合并后的事实/缺口按预期增减  
- [ ] 第二次生成前档案中已有第一次合并内容  
- [ ] 历史记录可查（若 save_history=true）  
- [ ] 不关联档案时仍可单次生成（回归冒烟，本用例外可另跑）

## 失败常见原因

- 服务未重启，旧代码无 `/api/customers`  
- 前端缓存未刷新  
- merge 时 remove_gaps 原文与档案不一致（必须逐字相同）

## 手工 UI 路径（对照）

1. 打开首页 → 新建客户「华南精工汽配（测试）」  
2. 勾选演示模式 → 贴拜访#1 纪要 → 生成  
3. 下方合并区写入事实/缺口 → 合并进档案  
4. 改本场目标为方案沟通 → 贴拜访#2 纪要 → 生成  
5. 打开档案详情：应显示已拜访 2 次，事实/缺口已更新
