按顺序做。每一步填完再点对应按钮。  
地址：http://127.0.0.1:8765 （先 `Ctrl+F5` 强刷）

**角色假设（本用例固定）：** 你是 **深信服售前**，主推 **aTrust 零信任 / 安全远程接入**；客户是华南精工汽配；竞品为短名单里另一家头部安全厂商。  
「我方产品要点」一律按深信服公开口径演练填写（非内部报价机密）。

建议全程勾选：**演示模式**（不调大模型，只测流程更快）。若要测真实七段质量，取消演示模式即可（仍用同一套深信服要点与纪要）。

### 深信服要点块（我方产品要点 · 整段复制）

```text
【我方角色】深信服售前
【产品/方案名称】深信服 aTrust 零信任访问 / 安全远程接入（公开口径演练）
【一句话定位】面向多分支制造企业，收敛传统 VPN 暴露面，按身份与权限控制远程/运维访问，补齐审计，支持 1～2 分支试点及与旧 VPN 并存。
【主要能力点】
1. N-access 身份化安全接入，减少共用账号与端口暴露
2. N-policy 按人/应用最小授权与回收口径
3. N-audit 访问日志与审计材料组织（等保映射待项目确认）
4. N-integrate 与 AD/LDAP/SSO 等身份源对接（协议细节待确认）
5. N-branch 多分支策略统一纳管
6. N-pilot 试点成功标准与时间盒
7. N-migrate 与传统 VPN 并存/灰度，不承诺一周硬切
8. N-ops/N-cost 实施培训与范围口径；价格走商务，本 brief 不写报价
【讲解纪律】不编造并发/性能数字；不未核实贬低竞品；客户现场只演示深信服产品，不演示本备战工具。
```

### 纪要 #1（整段复制 · 深信服初访）

```text
【我方】深信服售前初访
【客户】华南精工汽配（测试）
参会：安全周工、网络张工、采购；深信服售前。

周工：远程运维主要靠传统 VPN，账号有共用，审计对不上人。有 AD。集团要收敛暴露面，提过零信任，但不一定上全套大而全，先把远程和关键运维通路管住。旧 VPN 不能硬切，至少并存一段时间。想先 1～2 个分支试点。

张工：VPN 体验和专线成本也关心；分支策略不太统一。

采购：短名单里还有一家头部安全厂商（非深信服）。会看效果、总价、服务、交期。

我方备忘：主打 aTrust/身份接入+审计+试点并存；不问口承诺并发；问清竞品已承诺范围与等保级别、试点工厂。

待确认：等保级别、试点工厂名单、竞品已承诺范围。
```

勾选确认：
- [x] 演示模式  
- [x] 写入本地历史  
- [x] 关联档案时记录为一次拜访  

点 **生成七段草稿**，等结果出来。

## 若某步失败

| 现象 | 处理 |
|------|------|
| 新建没反应 | 强刷；应出现名称输入框，不是系统弹窗 |
| 关闭缺口删不掉 | 必须与「开放缺口」里逐字相同 |
| 没有拜访#2 | 确认勾了「关联档案时记录为一次拜访」，且选中的是同一客户 |
| 输出一直转 | 演示模式应很快；若未勾演示会调 API，等 1～2 分钟 |

测完可把结果简单记在本文件末尾（日期 / Pass 或 Fail / 卡在第几步）。
