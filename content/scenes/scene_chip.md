# 场景包：芯片 / 模拟信号链技术销售（chip · 轻量）

适用投递方向：纳芯微、思瑞浦、TI、晋华、渠梁等 **FAE / 技术销售** 向沟通准备。

> **轻量定位：** 软工背景使用者优先用本包生成「会前问题 + 待向原厂/FAE 确认清单 + 讲解骨架」。  
> **不假装**能完成完整器件选型或电路设计；无依据的参数一律「待确认」。

---

## 1. 场景边界

### 覆盖

- 应用场景澄清（测什么物理量、环境、接口）
- 关键指标与约束的提问清单
- 竞品对标维度（定性）
- 会前准备：要原理图/规格书/样品需求

### 明确不做

- 给出具体推荐型号与完整 BOM（除非 `our_product_brief` 已写明且使用者会后核实）
- 编造精度、温漂、EMI、交期、价格
- 替代实验室验证与 FAE 支持

---

## 2. As-Is 分析要点

| 线索 | 要写清什么 |
|------|------------|
| 应用 | 终端产品/板级功能是什么 |
| 现状器件 | 在用什么方案/竞品（有则记下） |
| 痛点 | 性能不够、供货、成本、认证、设计风险 |
| 阶段 | 概念 / 打样 / 量产 / 降本替换 |

---

## 3. 标准需求类型（轻量）

| ID | 含义 |
|----|------|
| `N-sense` | 传感/信号采集需求 |
| `N-drive` | 驱动/功率相关需求 |
| `N-interface` | 接口与信号链匹配 |
| `N-reliability` | 可靠性/车规/工规等（级别待确认） |
| `N-supply` | 供货与生命周期 |
| `N-sample` | 样品与评估支持 |
| `N-designin` | Design-in 支持（资料、参考设计） |
| `N-cost` | 成本与替代动机 |

---

## 4. 对比维度（轻量）

`D-spec`（关键指标，无数据则缺口）、`D-eco`（生态与参考设计）、`D-supply`（供货）、`D-support`（FAE/样品）、`D-cost`（成本口径）、`D-qualify`（认证/导入难度）

---

## 5. Discovery 必问（优先）

1. 终端应用与工作环境（温度、干扰、供电）？  
2. 必须满足的关键指标有哪些（请客户给目标值，勿你编）？  
3. 当前方案/竞品是什么？哪里不满意？  
4. 项目阶段与上量时间？  
5. 需要样品、EVB、还是参考设计？  
6. 谁做选型决策（硬件/采购/质量）？  
7. 有无车规/安规/客户指定认证？  
8. 对交期与第二供货的要求？  

每条未知都进入「待向 FAE/原厂确认」。

---

## 6. 讲解骨架

1. 复述应用与约束（As-Is）  
2. 列出客户需要的能力类型（非具体型号，除非 brief 有）  
3. 说明我方 brief 可对齐点 + **大量待确认**  
4. 推进：要规格目标表、原理图关键页、样品申请、约 FAE  

---

## 7. 额外硬约束

1. 输出中必须有一节 **「待向原厂/FAE 确认」**（可放在第 7 段）。  
2. 禁止推荐具体型号数字指标，除非输入 brief 已写且标注 `from_our_brief`。  
3. 竞品异同以维度与问题为主，不编造对方 datasheet 数据。
