# 我方产品要点示例（通用视觉占位）

> **说明：** 本文件为阶段 2 演练用**虚构公开口径占位**，不代表任何真实厂商的官方规格。  
> 实际投递某公司时，请复制 `our_product_template.md`，改写为该公司公开产品线后再用作 `our_product_brief`。

可作为生成输入字段 `our_product_brief` 直接粘贴下文「可粘贴区」。

---

## 可粘贴区（our_product_brief）

```text
【产品/方案名称】
VisionLine 外观在线检测方案（演练占位）

【一句话定位】
面向离散制造产线的外观缺陷在线检测：支持试样验证、配方换型、结果存图与常见 PLC/上位对接；具体检出指标以试样报告为准。

【主要能力点】
1. 外观缺陷在线检测（N-detect）：支持常见表面类缺陷的成像与判定流程；指标待试样确认。
2. 误检阈值与复核（N-false）：支持阈值阈值、可疑件人工复核流程说明（细节以公司资料为准）。
3. 多品种配方/换型（N-changeover）：品种配方保存与切换，降低纯手改参数依赖（易用性对比需现场看）。
4. 节拍匹配选型支持（N-takt）：可按产线节拍讨论相机/光源/工位方案；不口头承诺具体 ms。
5. 存图与结果输出（N-trace）：检测结果与图像可按项目约定存储/导出。
6. PLC/IO 与上位对接（N-integrate）：支持常见 IO/工业通信对接类型（具体协议待项目确认）。
7. 试样/POC（N-poc）：可提供试样流程与成功标准表（时间盒与投入边界需商务/应用共同定）。
8. 调试培训与交付边界（N-support / N-cost）：含调试支持与操作培训口径；报价与范围以商务为准，本 brief 不写价格。

【相对通用竞品的讲解准备（未核实前仅内部备战）】
- 可强调：试样闭环、配方换型、存图追溯、交付培训边界相对清晰。
- 需并列承认：价格与交期走商务；最终效果看试样与工况。
- 禁止未核实就说：任何具体检出率、比某竞品「一定更准/更便宜」。
```

## 结构化备份（同内容）

### 产品/方案名称

VisionLine 外观在线检测方案（演练占位）

### 一句话定位

面向离散制造产线的外观缺陷在线检测：试样验证、配方换型、存图与常见产线对接。

### 主要能力点（对齐 need_type）

| 能力点 | 对应 need_type | 可讲的证据类型 | 备注 / 边界 |
|--------|----------------|----------------|-------------|
| 外观缺陷在线检测 | `N-detect` | 试样、行业案例（占位） | 具体指标待试样 |
| 误检阈值与复核 | `N-false` | 流程说明、调参演示脚本 | 不以口头率承诺 |
| 多品种配方换型 | `N-changeover` | 操作演示 | 易用性现场看 |
| 节拍匹配选型支持 | `N-takt` | 选型逻辑说明 | 不编造 ms/fps |
| 存图与结果输出 | `N-trace` | 接口/导出说明 | 存储策略项目定 |
| PLC/IO 与上位对接 | `N-integrate` | 联调范围说明 | 协议待确认 |
| 试样 / POC | `N-poc` | POC 流程与成功标准表 | 时间盒需双方定 |
| 调试培训与范围口径 | `N-support` / `N-cost` | 服务边界说明 | 不写具体报价 |

### 常见集成与交付

- 对接类型：常见 IO / 工业通信 / 结果输出（具体协议待确认）
- 交付与培训：调试支持 + 操作培训（公开演练口径）
- POC / 试样：支持，成功标准与时间盒待定
