## 1. 客户画像（事实 / 假设 / 缺口）

### 事实
- 汽配冲压钣金，服务整车厂；近期外观缺陷流出，客户不满。
- 现状人工目视抽检，夜班更不稳；目标缺陷：划伤、凹坑、边缘缺料。
- 希望在线视觉；要留图；要 PLC OK/NG；MES 本期不一定上。
- 换型多（一天或两三个品种）；工位挤、灯乱；节拍为「几秒级」但无精确值。
- 星瞳视觉在谈、愿试样、未送样、正式报价未出；客户感觉整包偏贵（无数字）。
- 干系人：质量王工、设备李工、采购（货比三家：效果/交期/总价/服务）。

### 假设
- 三类缺陷在当前工况下可用视觉稳定检出（`assumed`）→ 试样验证。
- 存在可安装的在线工位（`assumed`）→ 要尺寸与节拍。
- 星瞳与我方同属「可试样的视觉方案」竞争（`implied`）→ 对齐对比维度。

### 缺口
- 精确节拍、工位尺寸、判定标准书面版、PLC 信号形式、星瞳承诺范围与报价、最终拍板人。

### 干系人线索
- 质量要效果与证据；设备要可装可节拍；采购要比价与服务。拍板人待确认。

## 3. 痛点与需要的产品

### 痛点
- **P1** 流出客诉 → `quality` / high → `N-detect` / `must` / `stated`
- **P2** 换型怕难调 → `efficiency` → `N-changeover` / `must` / `stated`
- **P3** 工位挤灯乱 → `delivery` → `N-install`（及 `N-takt`）/ `should` / `stated`
- **P4** 要留图 + PLC；MES 非必须 → `N-trace` + `N-integrate` / `should`；MES=`non_goal` / `stated`
- **P5** 要试样并货比三家 → `N-poc` + `N-cost` 口径 / `must` / `stated`

### 需求清单
| ID | need_type | 需要对齐我方 | 优先级 | 契合度 |
|----|-----------|--------------|--------|--------|
| R1 | N-detect | VisionLine 外观在线检测 | must | strong（效果待试样） |
| R2 | N-changeover | 配方换型 | must | strong |
| R3 | N-poc | 试样/成功标准表 | must | strong |
| R4 | N-trace | 存图输出 | should | strong |
| R5 | N-integrate | PLC OK/NG | should | partial（协议待确认） |
| R6 | N-install / N-takt | 安装与节拍选型支持 | should | partial（缺数据） |
| R7 | N-support / N-cost | 培训与范围口径（价格商务） | should | partial |

**Must：** R1 R2 R3｜**Should：** R4 R5 R6 R7｜**Non-goal：** 本期 MES

## 4. 我方与其他产品的异同

对比：VisionLine vs 星瞳视觉 vs 人工抽检

| 维度 | 客户在意 | 相同点 | 差异与讲法 | 待核实 |
|------|----------|--------|------------|--------|
| D-detect | high | 星瞳与我方都称可做视觉 | 相对人工可强调在线可验证；对星瞳不贬低，打同条件试样 | 试样结果 |
| D-changeover | high | — | 我方 brief 有配方换型，可强调；星瞳未知 | 星瞳换型方式 |
| D-poc | high | 双方愿试样 | 主打成功标准与时间盒 | 星瞳试样条件 |
| D-trace | medium | — | 相对人工留图优势明确 | 星瞳存图 |
| D-cost | high | 都会被比价 | 不说更便宜；谈范围口径 | 正式报价维度 |
| D-install/D-takt | high | 都需现场数据 | 无数据不争快慢 | 节拍与尺寸 |

**备战结论：** 主打相对人工的可验证检出+留图+换型+清晰 POC；对星瞳只打同条件对比，不打未核实价格/效果贬低。

## 6. 讲解提纲

- **块 A（P1/R1）：** 复述客诉与抽检现状 → VisionLine 在线检出能力 → 公司试样流程与成功标准表 → 不报检出率。  
- **块 B（P2/R2/R4）：** 配方换型 + 留图 → 公司操作演示/存图说明 → 星瞳换型能力标待核实。  
- **块 C（P3/R5/R6）：** 先收现场数据再谈工位；PLC OK/NG 范围说明；无数据不承诺细节。  
- **块 D（P5）：** POC 时间盒与对比维度清单；下一步约试样。  
- 全部 Demo 指向**公司产品**，不演示本工具。

## 7. 风险 / 待确认 / 下一步

- **风险：** 装不上/节拍不够；星瞳试样领先；采购只压价无验收口径。  
- **待确认：** 节拍、尺寸、标准与样件、PLC、星瞳范围、真实官方案例（替换占位 brief）。  
- **下一步：** 要样件与标准；要节拍与草图；发成功标准表；内部替换真实产品 brief；客户现场不打开本工具。
