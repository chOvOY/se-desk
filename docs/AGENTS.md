# 多智能体说明

本项目在真实生成模式下，默认使用开源 **LangGraph** 编排多个专业智能体，并行产出会前草稿后再汇总。

## 智能体列表

| 智能体 | 职责 |
|--------|------|
| 客户画像智能体 | 输出第 1 段：事实 / 假设 / 缺口与干系人线索 |
| 现状与需求智能体 | 输出第 2–3 段：客户当前怎么做、痛点与需要的产品 |
| 竞品对比智能体 | 输出第 4 段：我方与其他产品的异同 |
| 讲解与风险智能体 | 输出第 5–7 段：提问清单、讲解提纲、风险与下一步 |

汇总节点负责加上文首声明，并按固定顺序拼接七段 Markdown。

## 容错（保证同一张图跑完）

四个专业节点**并行**；`assemble` 为硬汇合。单节点若超时或抛错：

1. 按 `AGENT_MAX_RETRIES` 重试；
2. 仍失败则写入该段的**降级占位 Markdown**（保留固定标题），并记入 `agent_warnings`；
3. 其他已完成节点不受影响；汇合后文首提示「部分智能体已降级」。

相关配置：`AGENT_TIMEOUT_SECONDS`（默认 90）、`AGENT_MAX_RETRIES`（默认 1）。

## 运行方式

- `USE_MULTI_AGENT=true`（默认）：走多智能体流水线，返回模式 `multi_agent`
- `USE_MULTI_AGENT=false`：回退为单次大模型生成，返回模式 `live`
- `DRY_RUN=true` 或勾选演示模式：不调模型，返回样例

## 代码位置

- `app/agents/graph.py`：编排图
- `app/agents/nodes.py`：各智能体提示词与调用
- `app/agents/state.py`：共享状态
