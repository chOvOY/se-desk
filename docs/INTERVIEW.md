# 对外讲述口径（销售工程师备战台）

适用于：深信服**客户经理**、海康机器人**销售工程师**等 ToB 销售相关岗位面试。

## 三句话（推荐口述）

1. **是什么：** 这是我为自己客户拜访与方案沟通做的会前备战台，用来把见客户前的准备做成标准动作。  
2. **怎么用：** 输入纪要和我方产品/方案要点，生成客户现状、需求、竞品对比、提问清单和讲解提纲；客户进名录做多访累计与阶段跟进。  
3. **价值：** 拜访前更清楚该问什么、该讲什么、哪些不能乱讲；同一客户连续跟进时信息不丢。

## 简历项目条（当前版）

**销售工程师备战台** | 个人项目 · 2026-09 ~ 至今  

定位：服务本人销售工作的会前准备工具（非客户侧产品）

1. 围绕企业客户沟通场景，设计客户信息结构化分析系统，实现客户画像、业务现状分析、需求痛点整理、Discovery 问题清单等模块功能，支持客户交流信息的统一整理与分析。  
2. 设计客户档案管理与多轮跟进模块，实现客户基本信息、行业背景、沟通记录、推进阶段及待确认事项的结构化存储，支持历史信息沉淀与后续复用。  
3. 基于大语言模型构建业务内容生成模块，结合客户会议纪要、产品能力描述及应用场景信息，生成需求匹配建议、方案沟通提纲及后续推进计划，辅助售前交流准备。  
4. 针对企业应用场景中 AI 生成内容可靠性问题，引入事实、假设、待验证信息分级机制，并结合人工审核流程提升生成内容的可控性与实际应用价值。

## 面试时怎么对口讲（同一条经历，两种侧重点）

### 深信服 · 客户经理

强调：**客户经营、需求挖掘、多访跟进、方案推进节奏**

- 这个工具帮我把「见客户前要摸清什么、问什么、怎么跟进」固定下来。  
- 名录里的推进阶段、开放缺口，对应客户从摸底到方案沟通的经营过程。  
- 竞品对比与待核实，是为了在客户面前把边界讲清楚，不乱承诺。

### 海康机器人 · 销售工程师

强调：**场景现状、需求对齐、方案讲解、竞品与试点准备**

- 这个工具帮我把客户现场/产线现状、真正要解决的问题、和竞品怎么比，整理成讲解前草稿。  
- 提问清单对应 Discovery；讲解提纲对应方案沟通前的结构。  
- 事实/假设/缺口分层，避免在客户现场把未核实的检出率、节拍等讲死。

## 追问时怎么答

| 可能追问 | 回答要点 |
|----------|----------|
| 为什么自己做工具？ | 客户拜访前准备容易散，我想用结构化方式把经营准备和方案准备做扎实。 |
| 和直接问 ChatGPT 有什么区别？ | 固定拜访准备结构、客户名录多访累计、证据分层，减少漏项和乱承诺。 |
| 有没有真实客户？ | 流程用高保真模拟案例验证；入职后替换为真实客户纪要与公司产品要点即可。 |
| 技术栈？（若问到） | 提示词 + FastAPI 本地工作台 + OpenAI 兼容大模型接口。 |
